# AI Olympiad Wiki

## Who Is This For?

This wiki is primarily intended for:

* AI Olympiad participants
* Students learning machine learning
* Competitive programming students exploring AI
* Teachers and mentors
* Anyone looking for a concise AI reference

## Disclaimer

AI Olympiad Wiki is an educational resource and is not an official publication of any particular AI Olympiad organization unless explicitly stated otherwise.

Competition formats, rules, libraries, and allowed tools may change. Always check the official rules for the competition you are participating in.
